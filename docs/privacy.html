WaveTagger Rec プライバシーポリシー / Privacy Policy

WaveTagger Rec は、効果音の収録を行う個人用の録音アプリです。ホームは こちら。

取得する情報

  • マイクの音声:録音するときだけ、端末のマイクを使います。録音した WAV は端末内に保存されます。
  • Google アカウントの認可:Google Drive への送信のために、Google の認可を受けます。取得するのは、アクセス用のトークンだけです。パスワードは扱いません。

Google Drive へのアクセス

  • 使うのは、利用者が設定画面で指定した保存先フォルダへ、録音ファイルをアップロードすることだけです。
  • それ以外の Drive のファイルを、読む、変更する、削除することはありません。
  • Google から得た情報の利用は、Google API サービスのユーザーデータに関するポリシー(限定的使用の要件を含む)に従います。

情報の共有・保存

  • 録音、トークン、設定は、利用者の端末と、利用者自身の Google Drive にのみ保存されます。
  • 開発者や第三者のサーバーには、何も送信しません。広告、解析、トラッキングも使いません。
  • 端末内のトークンは、アプリの削除、または Google アカウントの「サードパーティによるアクセス」から、いつでも取り消せます。

お問い合わせ

GitHub の Issues へお願いします。

English summary

WaveTagger Rec is a personal sound-effects recorder. It uses the microphone only while recording, and uploads the recordings only to the Google Drive folder you choose. It does not read, change or delete any other Drive file, and it sends nothing to the developer or any third party. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
