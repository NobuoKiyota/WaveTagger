# WaveTagger Rec の設定 (最初の 1 回だけ)

スマホのブラウザで録音すると、48 kHz / 24 bit の WAV が自動で Google Drive の指定フォルダに保存されます。
パソコンの WaveTagger の Inbox がそのフォルダを監視しているので、あとは自動で取り込まれます。

## 1. Google Cloud で OAuth クライアント ID を作る (無料・約 10 分)

1. <https://console.cloud.google.com/> を開き、プロジェクトを新規作成 (名前は何でもよい。例: WaveTagger)。
2. 「API とサービス」→「ライブラリ」→ **Google Drive API** を有効にする。
3. 「API とサービス」→「OAuth 同意画面」
   - ユーザーの種類: **外部**
   - アプリ名: WaveTagger Rec、サポートメール・連絡先: 自分のアドレス
   - スコープは追加しなくてよい (次のステップで画面から使う権限として扱われる)
   - **テストユーザー** に自分の Google アカウントを追加 (公開はしない)
4. 「API とサービス」→「認証情報」→「認証情報を作成」→ **OAuth クライアント ID**
   - アプリの種類: **ウェブ アプリケーション**
   - 承認済みの JavaScript 生成元: `https://nobuokiyota.github.io`
   - 作成後に出る **クライアント ID** (`xxxx.apps.googleusercontent.com`) をコピー (クライアントシークレットは不要)

テストユーザーのまま使うと、ログイン時に「このアプリは Google で確認されていません」と出ます。
「詳細」→「WaveTagger Rec (安全でないページ) に移動」で進めます (自分で作ったアプリなので問題ありません)。

## 2. 公開 (GitHub Pages)

リポジトリの Settings → Pages → Branch を `main`、フォルダを `/docs` にして保存。
数分後に <https://nobuokiyota.github.io/WaveTagger/> で開けます。

## 3. スマホで

1. Android の Chrome で上の URL を開き、メニューから「ホーム画面に追加 / アプリをインストール」。
2. 右上の「設定」に次の 2 つを入れて「保存」。
   - OAuth クライアント ID: 手順 1 でコピーしたもの
   - 保存先フォルダ: Drive で、パソコンの Inbox が見ているフォルダ (例: `PCM録音/_Inbox`) を開き、その URL を貼る
3. 「Google に接続」を押してログインし、権限を許可する。
4. 録音の前に、「入力レベルを確認」を押すと、録音せずにマイクのレベルが見えます (ピーク、LUFS)。声を出したり、音を鳴らして、メーターが 0 dB に届かない程度 (目安は -12〜-6 dB) になるよう、マイクとの距離を調整します。メーターをタップすると、ピーク・CLIP・Integrated がリセットされます。
5. 「録音」を押すと開始、「停止」で保存してそのまま Drive へ送信。

### 録音フォーマット

画面の「録音フォーマット」で、**ステレオ / モノラル**、**48 / 44.1 kHz**、**24 / 16 bit** を切り替えられます (初期値は ステレオ・48 kHz・24 bit。端末に覚えさせます)。録音中は変えられません。レベル確認中に変えると、新しい設定でマイクを開き直します。
- ステレオを選んでも、端末のマイクが 1 チャンネルなら、モノラルで録音されます (画面に表示されます)。
- モノラルを選んで、2 チャンネルのマイク (外付けなど) をつないでいるときは、2 つを混ぜて 1 チャンネルにします。
- 16 bit はファイルが小さくなります (ディザつき)。素材として使うなら、24 bit のままがおすすめです。

### レベル表示の見かた

- メーター: 入力のピーク。ステレオのときは **L と R の 2 本** (左右の偏りが見えます。L と R がまったく同じ動きなら、中身は同じ音のコピーです)、モノラルのときは 1 本 (M)。白い線はピークホールド。CLIP はサンプルが 0 dBFS に当たった印で、タップするまで残ります。
- Momentary: 直近 0.4 秒のラウドネス。Short-term: 直近 3 秒 (3 秒たつまでは、あるだけの長さ)。Integrated: 録音を始めてからの全体 (無音は除く)。単位は LUFS (ITU-R BS.1770 / EBU R128)。

## 注意

- 録音中は画面を点けたままにしてください (画面を消す・別アプリに切り替えると、ブラウザがマイクを止めることがあります)。
- 接続は約 1 時間で切れます。切れていると、停止したときにログインの小さなウィンドウが出ます。オフラインで録った分は「送信待ち」として端末に残り、あとから送れます。
- 端末が 48 kHz に対応していない場合、実際のレートで録音され、画面に表示されます。
- 権限は「Drive のファイルの閲覧・作成」です (`drive` スコープ)。テストユーザーの自分だけが使えます。トークンは端末のブラウザの中にだけ保存されます。
